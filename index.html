Bienvenido a mi sitio web personal

Este sitio web ha sido creado como parte de la asignatura de Fundamentos de Ingeniería Informática. Su objetivo es mostrar los conocimientos adquiridos sobre HTML y GitHub a través de un sitio web personal bien estructurado y organizado.

A lo largo de las distintas secciones se puede encontrar información sobre mí, mi grado universitario, un tema de interés personal o académico, mi red de contactos académicos y una página de contacto.

Secciones del sitio web

  • About: información personal, currículum vitae, imágenes y enlaces a redes sociales.
  • Degree: descripción del grado y de las asignaturas que lo componen.
  • Topic: desarrollo de un tema de interés personal o relacionado con la carrera.
  • Net: enlaces a las páginas web de otros compañeros.
  • Contact: formulario para ponerse en contacto conmigo.

Todas las páginas del sitio web comparten una estructura común y utilizan una hoja de estilos CSS externa para mantener un diseño coherente y uniforme.

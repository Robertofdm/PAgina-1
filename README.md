# PAgina-1
## Proyecto Web Individual – Fundamentos de Ingeniería Informática

## Descripción general
Este proyecto consiste en el desarrollo de un sitio web estático como parte del trabajo
individual de la asignatura Fundamentos de Ingeniería Informática. El objetivo principal
del proyecto es aplicar conceptos de organización del contenido, estructura de un sitio web
y control de versiones mediante GitHub, más que el diseño visual.

El sitio web presenta información personal, académica y temática, organizada en distintas
páginas HTML interconectadas.

---

## Estructura del proyecto
El repositorio está organizado de la siguiente manera:

- `public/`: contiene todas las páginas HTML del sitio web.
  - `index.html`: página principal (Home).
  - `about.html`: información personal, currículum e imágenes.
  - `degree.html`: descripción del grado y asignaturas por curso.
  - `fii.html`: información detallada de la asignatura Fundamentos de Ingeniería Informática.
  - `topic.html`: desarrollo de un tema de interés (Mallorca).
  - `net.html`: red de enlaces a compañeros.
  - `contact.html`: formulario de contacto (no funcional).
- `css/`: contiene los estilos CSS comunes a todas las páginas.
  - `styles.css`: hoja de estilos principal.
- `images/`: contiene las imágenes utilizadas en el sitio web.
- `README.md`: documento de diseño del proyecto.

---

## Navegación
El sitio web dispone de un menú de navegación común en todas las páginas, lo que permite
acceder fácilmente a las distintas secciones del proyecto. Todas las páginas comparten
una estructura base coherente para mantener la uniformidad del sitio.

---

## Tecnologías utilizadas
- HTML para la estructura y el contenido del sitio web.
- CSS para el diseño y la maquetación.
- Git y GitHub para el control de versiones y la publicación del proyecto.

---

## Uso de GitHub
El desarrollo del proyecto se ha realizado mediante un repositorio público de GitHub.
Se ha seguido la buena práctica de realizar commits independientes cada vez que se añadía
una nueva página HTML o se realizaban cambios significativos, lo que permite un correcto
seguimiento de la evolución del proyecto.

El sitio web se publica utilizando GitHub Pages.

---

## Problemas durante el desarrollo
Durante el desarrollo del proyecto surgieron algunas dificultades relacionadas
principalmente con la organización del repositorio, la correcta estructuración
de las páginas HTML y el uso de rutas relativas para enlazar archivos CSS e imágenes.

También fue necesario familiarizarse con el flujo de trabajo de GitHub, en especial
con la realización de commits independientes y la publicación del sitio web mediante
GitHub Pages. Estos problemas se resolvieron mediante pruebas progresivas y revisión
de la documentación.

---

## Conclusiones
Este proyecto ha permitido aplicar de forma práctica los conocimientos adquiridos
en la asignatura Fundamentos de Ingeniería Informática, especialmente en lo relativo
a la organización del contenido, la estructuración de un proyecto y el uso de sistemas
de control de versiones.

El trabajo ha servido como una introducción al desarrollo de proyectos de software
bien documentados y versionados, sentando una base sólida para futuros proyectos
académicos y profesionales.
